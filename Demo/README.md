# Maquette de formation BIMaestro

`BIMaestro_Apprentissage_2024_20261002_140035.rvt` est la maquette Revit 2024 de référence. Les fichiers RVT plus anciens restent disponibles pour les essais précédents. Utiliser **Créer et ouvrir la maquette de formation** avec la nouvelle version de BIMaestro pour produire, au besoin, un autre fichier horodaté. La scène comprend un mur traversé par une canalisation pour **Auto réservation**, un petit espace meublé pour **Qui a fait ça ?**, deux réseaux de canalisations avec coudes et une gaine avec coudes pour **Calcul des canalisations**, quatre places `CML_Parking` pour **Organisateur**, et deux vues pour **Gabarit de vue**. Le parcours **Gestion Excel** ajoute, si nécessaire, quatre autres places, une vue 3D et leur nomenclature dédiée dans une maquette existante.

Les vues 3D sont créées en niveau de détail **Élevé** et en style visuel **Couleurs uniformes**. L'ouverture d'un parcours applique aussi ces réglages aux vues d'une maquette de formation déjà créée ; enregistrer cette maquette pour les conserver dans son fichier.

Dans Revit, ouvrir l'onglet **BIMaestro**, puis **Couleurs > Parcours guidés**. Commencer par **Découverte rapide** pour voir les huit fonctions, puis choisir à la fin si l'on souhaite pratiquer. Pendant un exercice détaillé, Pikachu indique d'abord la commande du ruban, puis les commandes dans sa fenêtre lorsque la commande utilise WPF. Le bouton **Créer et ouvrir la maquette de formation** régénère une maquette vierge. Il ne remplace pas un fichier existant : Revit crée alors un fichier horodaté.

À l'ouverture d'une maquette `BIMaestro_Apprentissage_*.rvt`, Pikachu propose directement les huit exercices. Cette invitation apparaît aussi après la création d'une nouvelle maquette. **Plus tard** ferme le choix sans lancer d'exercice ; le bouton **Parcours guidés** reste disponible pour le relancer. Chaque ouverture de la maquette ne déclenche qu'une invitation.

La **découverte rapide** ne modifie pas le projet. À la fin, elle propose les huit exercices guidés ou la possibilité de s'arrêter. Pour passer directement à la pratique, déplier **Aller directement aux exercices détaillés** dans la première fenêtre. Les parcours de calcul, de numérotation et d'import Excel vérifient les valeurs produites dans la maquette.

Le guide avance lorsque l'action demandée est effectuée. Si un filtre ou un réglage est déjà actif, le bouton **Suivant** permet de continuer. L'étape de restauration attend qu'un élément soit effectivement recréé ; Auto réservation confirme après l'exécution qu'une nouvelle réservation a été placée.

Le bouton **Recommencer les exercices de la maquette** remet les deux meubles d'exercice à leur position initiale et retire seulement les réservations marquées comme créées pendant le parcours guidé. Il ne remet pas à zéro les couleurs personnelles. Les anciennes entrées d'historique restent disponibles ; le parcours suivant crée de nouvelles suppressions.

Dans **Auto réservation**, le guide explique le support, la forme, le réseau, le mode manuel/automatique, les liens, puis l'onglet **Familles** (type chargé, import RFA, mapping des dimensions, placement vertical) et **Réglages** (arrondi et Dynamo). Les étapes de configuration sont explicatives et ne remplacent pas la famille fournie avec la démo. Le guide laisse le mode automatique désactivé : sélectionner dans la vue 3D la canalisation, puis le mur, pour poser soi-même la réservation.
Si le mauvais élément est choisi, Pikachu explique lequel sélectionner et redemande le clic. Après la création, BIMaestro sélectionne et cadre la réservation pour en examiner la position et les dimensions.

Dans **Couleurs et vues**, le guide vise le bouton complet **Couleurs**, propose le style **Arc-en-ciel**, passe par **Fond et aperçu** pour changer la couleur du fond, puis par **Dossiers** et directement par l'onglet **Icônes**. Il fait ajouter une règle pour le dossier `Plans d'étage` et une autre pour `Vues 3D` ; il ne crée aucun type de vue Revit. Chaque règle associe le nom exact du dossier à une image. Pendant la saisie, la carte Pikachu se place en haut et laisse les nouvelles lignes accessibles.

Dans **Qui a fait ça ?**, le lancement du parcours supprime deux objets de mobilier marqués pour l'exercice. Ce sont de vraies suppressions enregistrées dans l'historique local ; le guide explique les filtres, la période, la recherche, les aperçus simple/détaillé, **Détails**, **Visualiser** puis **Restaurer les éléments**. Un troisième objet reste visible pour servir de repère. La maquette seule ne transporte pas le journal local : il faut lancer la préparation sur chaque poste.

Dans **Calcul des canalisations**, la vue 04 contient quatre tronçons DN100 et trois coudes, trois tronçons DN50 et deux coudes, ainsi qu'une gaine rectangulaire en trois tronçons avec deux coudes. Le parcours sélectionne les dix-sept éléments MEP, fait cocher **Inclure les gaines**, explique le filtre et l'export Excel, puis ouvre le récapitulatif. Relancer sans cocher les gaines pour comparer. Les longueurs géométriques avant les ajustements aux raccords sont 11 m pour DN100, 8 m pour DN50 et 9 m pour la gaine ; les longueurs calculées dans Revit peuvent être légèrement différentes après insertion des coudes.

Dans **Organisateur**, la vue 05 contient quatre places de la famille `CML_Parking`, sélectionnées par le parcours. Choisir le paramètre texte d'instance **CML_Numéros de place**, saisir `PK-` comme préfixe et choisir le format `001,002,003...`. Contrôler ensuite les nouveaux numéros dans les Propriétés Revit. Le guide laisse les autres éléments du projet hors sélection.

Dans **Gabarit de vue**, le parcours démarre dans `06 Gabarit source`. Exporter les réglages avec le bouton **Gabarit de vue** ; après l'export, Pikachu active `07 Gabarit cible` et indique comment importer le fichier en créant un gabarit Revit nommé. Le guide ne modifie pas automatiquement les réglages de la vue cible : l'utilisateur fait l'import avec la commande réelle.

Dans **Gestion Excel**, le parcours ouvre `08 Gestion Excel`, une nomenclature limitée à quatre places dédiées. Elle affiche le numéro de place, les **Commentaires** de secteur (modifiables) et le **Repère** (référence fixe). Exporter avec le bouton **Gestion Excel**, ouvrir le classeur dans `Documents\RevitLogs\Exports`, puis modifier une ou plusieurs valeurs dans l'onglet **Nomenclature** : `XL-003` → `XL-103` est un exemple, et le secteur peut aussi changer. Enregistrer et fermer le classeur avant de revenir sur le même bouton pour importer. L'onglet **Edition** reprend les valeurs de la nomenclature par formule ; ne pas modifier ses identifiants cachés ni le **Repère**. Pikachu refuse un repère altéré et vérifie dans Revit toutes les valeurs effectivement modifiées, puis ouvre `08 Parking Excel` et cadre les places. Si `CML_Numéros de place` n'est pas disponible comme champ de nomenclature, **Commentaires** sert de numéro : la nomenclature affiche alors deux colonnes, dont le **Repère** fixe.

**Bride auto** reste en attente d'une famille de bride compatible. Le type de pièce *Flange* existe dans Revit, mais la présence d'une famille RFA utilisable dans le contenu installé et chargée dans le projet dépend de l'installation. La commande BIMaestro requiert une famille non hébergée de catégorie **Accessoires de canalisation**, munie de connecteurs Piping ; les descriptions de côtés `Accessoire` et `Canalisations` améliorent l'orientation. `HYD_PN` sert à la sélection par pression lorsqu'il existe. Ajouter l'exercice après validation de la famille fournie.

Dans **Navigateur de familles**, Pikachu charge temporairement le [catalogue de formation](NavigateurFamilles/README.md) : 35 familles de mobilier, six dossiers principaux et le sous-dossier `Bureau/Salle de réunion`. Le parcours fait naviguer dans les dossiers, rechercher une famille et l'étoiler, retrouver ce favori dans l'onglet **Favoris**, comprendre les collections, puis consulter un aperçu 3D. L'étoile d'essai reste en mémoire : quitter le guide rétablit l'état des favoris personnels, sans ajouter de chemin de démonstration dans `Favorites.txt` ou `Collections.json`. Le guide montre aussi où générer les images PNG des cinq familles de salle de réunion ; Pikachu accompagne le choix des vues **A/B** pendant l'export. La génération reste facultative et ne démarre qu'au clic de l'utilisateur. Pour utiliser une famille, **double-cliquer** sur la carte `Bureau commun` charge la RFA dans Revit et lance son placement ; cliquer ensuite dans la vue, puis appuyer sur Échap. La phase finale montre la rosace **« . »** du bouton Famille et le chemin **Vue > Fenêtres > Interface utilisateur > Raccourcis clavier** pour attribuer, par exemple, **BF** à la commande `Navigateur de Familles:.` si ce raccourci est libre, ou un autre raccourci disponible. Frapper le raccourci choisi dans une vue ouvre la rosace ; faire un clic droit au centre, puis **Charger une collection > Favoris**, permet d'y retrouver temporairement la chaise étoilée et de la placer. En dehors du guide, la rosace montre les familles récentes et utilisées par défaut, et seules les collections réellement enregistrées y sont chargées. Quitter le guide rétablit les chemins personnels du navigateur ; le catalogue de formation est livré avec le plugin et ne nécessite pas le lecteur `P:`.

La génération d'une autre maquette exige un gabarit Revit MEP contenant canalisations et gaines, la famille `CML_Réservation rectangulaire murale.rfa` dans `Documents\Revit\Réservation`, `CML_Table ronde + chaise.rfa` dans `Documents\Revit` ou `Documents\Revit\A-Famille Revit\Mobilier`, et `CML_Parking.rfa` dans `Documents\Revit\A-Famille Revit\Voiture-camion`. Si le gabarit n'a pas de règles de coudes, le générateur charge les familles génériques depuis les bibliothèques Autodesk installées (2024, 2023, 2022 ou 2021).
