# Catalogue pour le tutoriel Navigateur de familles

La bibliothèque `Familles/Mobilier` contient 35 familles Revit (`.rfa`) copiées depuis la bibliothèque Autodesk locale de formation. Elle comporte six dossiers de cinq familles ; `Bureau/Salle de réunion` ajoute un second niveau avec cinq autres familles. Les fichiers sources ne sont pas modifiés.

Le parcours peut montrer la navigation dans l'arborescence, la recherche d'une famille, l'ouverture de son aperçu et son chargement dans le projet actif. `Images` est volontairement vide au départ pour permettre une démonstration explicite de la génération automatique des aperçus ; cette opération peut prendre du temps et doit être lancée par l'utilisateur.

Lors de la compilation, le catalogue est copié à côté de `BIMaestro.dll` dans `Demo/NavigateurFamilles/Familles`. Il ne dépend donc pas du lecteur réseau `P:` sur les autres postes. Le choix ultérieur d'une bibliothèque personnelle s'effectue dans les réglages du Navigateur de familles.
