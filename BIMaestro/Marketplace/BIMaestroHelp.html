BIMaestro

BIMaestro réunit dans un onglet Revit une suite d’outils conçus pour simplifier les tâches quotidiennes de production BIM.

Démarrage

  1. Fermez Autodesk Revit avant l’installation.
  2. Installez BIMaestro puis redémarrez Revit.
  3. Ouvrez l’onglet BIMaestro dans le ruban.

Compatibilité

Autodesk Revit 2022 à 2027, Windows 64 bits.

Désinstallation

Fermez Revit, puis désinstallez BIMaestro depuis les applications installées de Windows.
